# Kanak Prabhakar Systems Engineering Suite

Unified developer platform encompassing AST parsing, systems programming tooling, performance monitoring, and Indian vernacular code analysis.

## Overview
- `kp-adhikarana`: Central policy and permission broker.
- `kp-kriyasala`: Interactive execution workbench and laboratory runtime.
- `kp-svasthya`: System health and memory telemetry monitor.
- `kp-vyapaka`: Distributed workflow coordinator.
- See `START-HERE.md` for detailed sub-package architecture and launch sequences.

## Prerequisites
- Node.js 18+, TypeScript 5.0+, npm

## Build & Test
```bash
npm install
npm run build
npm test
```
