# Changelog

## [1.0.1] - 2026-09-02

Rebuilt on the finalized shared runtime; packaging and metadata polish. No breaking changes.


## [1.0.0] - 2026-09-02

Initial production release.

Detects and verifies installed compilers, interpreters, debuggers, build tools
and version control on your machine, each with a per-OS install hint when it's
missing. Includes a toolchain sidebar view, a visual dashboard, and a savable
diagnostic report.

### Notes
- Built on the shared @kanak-prabhakar/shared runtime, bundled in.
- Every result is read from your real environment — nothing is mocked.
